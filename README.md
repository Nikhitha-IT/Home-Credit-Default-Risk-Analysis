# 🏦 Home Credit Default Risk Analysis

![Project Cover](Images/Project_cover_page.png)

## 📌 Project Overview

This project presents an end-to-end Credit Risk Analysis Dashboard built using Power BI, SQL, DAX, Power Query, and Excel. The dashboard analyzes 307,511 loan applications from the Home Credit Default Risk dataset to uncover patterns that influence loan defaults and support data-driven lending decisions.

The project transforms raw financial data into an interactive business intelligence solution by combining data preparation, KPI development, data modeling, and insightful visualizations. Users can explore applicant demographics, income profiles, education levels, organization types, age groups, contract types, and regional ratings through interactive filters and dynamic charts.

Designed with a clean, professional layout, the dashboard enables financial institutions and business stakeholders to monitor key performance indicators, identify high-risk customer segments, and make informed credit risk decisions efficiently.

---

## 🎯 Business Problem

Financial institutions receive thousands of loan applications every day.

This dashboard helps answer important business questions such as:

- Which customer groups have the highest default rates?
- Which education levels are riskier?
- Which organization types have higher loan defaults?
- How does applicant income affect default?
- Which age groups are more likely to default?
- How are applications distributed across contract types?
- Does regional rating impact loan default?

## 💡 Key Business Insights

- Overall Default Rate is **8.07%**
- Male applicants show a higher default rate than female applicants.
- Lower education levels are associated with higher default rates.
- Younger applicants show comparatively higher default rates.
- Region Rating 3 has the highest default rate.
- Cash Loans account for the majority of loan applications.
- Certain organization types exhibit significantly higher risk.
