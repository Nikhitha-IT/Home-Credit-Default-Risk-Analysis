# Dataset Download Instructions

This project uses the **Home Credit Default Risk** dataset available on Kaggle.

## Dataset Source

https://www.kaggle.com/competitions/home-credit-default-risk

## Required Files

- application_train.csv
- bureau.csv
- previous_application.csv
- installments_payments.csv

## Steps

1. Sign in to your Kaggle account.
2. Join the competition if required.
3. Download the dataset.
4. Extract the ZIP file.
5. Copy the required CSV files into this folder.

> The dataset is not included in this repository due to licensing and distribution restrictions.
